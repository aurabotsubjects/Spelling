🔄 Updating to a New Version?

Your student data is stored in your browser's local storage — not inside the HTML file itself. This means simply replacing the file won't delete your data as long as you open the new file in the same browser on the same computer.

To be safe, always export a backup JSON before replacing the file, then load it into the new version using Load JSON if needed.

ℹ️ How Checkboxes Work

Each word has two buttons: ✓ Correct and ✗ Incorrect.
You can mark a word correct or incorrect as many times as needed across multiple test sessions.
Once marked correct, the word is highlighted green and the buttons lock — the word is mastered.
The progress charts and PDF report show correct vs incorrect attempt totals for each student.
